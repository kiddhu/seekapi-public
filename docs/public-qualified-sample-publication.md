# Qualified public sample release artifact

The optional source artifact is `data/public-agent-sample-publication.json`. Its absence preserves the current source-observation and aggregate acceptance page; `/china-supply-check/sample.json` returns 404 and discovery metadata contains no qualified-sample pointer. Prepared contracts are explicitly separate from deployed commercial availability.

The release coordinator supplies the exact-reviewed upstream strict producer and a production publication bundle:

```sh
npm run prepare:public-sample -- --source /protected/production-publication-bundle.json --validator /reviewed/source/public-agent-sample.ts
```

The alternative input is the canonical public JSON plus `--assets /protected/issued-publication-bundle.json`. Preparation calls the existing `parsePublicAgentSample` and `preparePublicSamplePublication(sample, assets)` functions, including source-image re-sanitization. It writes a release artifact only. No sourcing, payment, supplier contact or publication occurs. Explicitly labeled synthetic fixture bundles are refused.

The website accepts only public sample v2. Supplier identities and true platform addresses remain private; stable evidence references and scope/time summaries are public. Product pictures are existing sanitized source pixels, self-hosted at digest-addressed PNG paths. Customer reference images, metadata, raw source URLs and Provider responses cannot enter this artifact.

One build consumes the same JSON/HTML/asset hashes for the native sample page, conditional Agent JSON, Agent services manifest, ARD and llms text. The website verifies byte identity, image binding and a narrow privacy/passive-markup boundary. It does not implement another qualification or ranking engine. The full source/schema/qualification validation remains with the upstream producer.

A malformed, mismatched or unsafe artifact fails the build. Removing an approved artifact and rebuilding restores JSON 404, the legacy sample disclosures and pending metadata; the build removes only generated hash PNGs from the sample asset namespace. Registry publication and production Git-integrated deployment remain separate reviewed release actions.

Tests include a marked synthetic dependency preview fixture generated by the strict producer. It proves the website rendering and artifact seam; it is not source qualification, a customer result, a testimonial or a production publication artifact. Original search pools and historical ranking weights remain unrecorded when the historical source did not retain them.
